# Приложение эксперта

Шаблон Telegram Mini App для эксперта: главная, бесплатные материалы по темам, продукты с оплатой, отзывы, заявка на консультацию.

- `index.html`, `styles.css`, `app.js` — общий шаблон.
- `experts/<id>/content.js` — данные конкретного эксперта, картинки в `experts/<id>/img/`.
- Открыть: `index.html?e=<id>`.

## Новое демо из канала

```bash
python3 tools/generate.py <username или t.me/ссылка> [--id имя]
```

Скрипт берёт публичные данные канала (описание, аватар, посты, отзывы) и собирает черновик `experts/<id>/content.js`.
Продукты и цены определяются эвристикой — перед отправкой эксперту проверьте их по отчёту, который печатает скрипт.

Демо: https://kmkrnk.github.io/expert-app/?e=<id>
